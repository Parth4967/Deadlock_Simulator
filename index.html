Coffman's 4 Necessary Conditions E. G. Coffman (1971)
1. Mutual Exclusion

At least one resource must be non-shareable; only one process can hold it at any given moment.

2. Hold and Wait

A process must hold at least one resource while waiting to acquire additional resources held by others.

3. No Preemption

Resources cannot be forcibly seized; they can only be released voluntarily after the process finishes.

4. Circular Wait

A closed chain of processes exists: P0 waits for P1, P1 waits for P2, and Pn waits for P0.

Single vs Multiple Instance Graph Theorems

Theorem 1: If every resource has only 1 instance, a cycle in the Resource Allocation Graph (or Wait-For Graph) is necessary AND sufficient for deadlock.

Theorem 2: If resources have multiple instances, a cycle is necessary but NOT sufficient! Use our Preset "Multi-Instance Cycle (Safe)" to observe a cycle where no deadlock exists.

Recovery Trade-offs

Process Termination: Aborting all deadlocked processes has high cost. Aborting one-by-one by minimum cost minimizes wasted CPU cycles.

Resource Preemption: Requires state checkpoints. Starvation must be prevented by keeping an aging counter so the same victim is not repeatedly selected.
